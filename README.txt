Grooving Room v1.4 - GitHub Pages upload package

Upload all files in this folder to the ROOT of your GitHub repository (not the ZIP itself).
Files: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.

GitHub Pages setup: Repository Settings > Pages > Deploy from a branch > main > /(root) > Save.

Note: the member password is a convenience gate only; static site source is public and can be inspected. Practice records are saved locally in each browser/device.
